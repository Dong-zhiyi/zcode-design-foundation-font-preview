注意事项

  • 必须通过 http(s) 访问，不要双击 index.html。浏览器把 file:// 页面视为不透明来源（origin: null），会拦截加载任何本地字体文件——包括和页面同目录的（CVE-2019-11730 之后的 Chrome / Edge / Firefox 都这样）
  • 部署时 index.html 与 fonts/ 必须放在同一目录（页面用相对路径 ./fonts/... 加载）
  • 想换字体来源：index.html?alibaba=https%3A%2F%2Fcdn.example.com%2Ffonts%2F（值需 encodeURIComponent）
  • 想减小体积：删掉两个 Noto 字体（合计 42MB），页面会自动回退系统字体，其余不受影响
  • 阿里巴巴普惠体 3.0 起已允许自行托管；公开 CDN 或随产品分发前，请核对官方现行法律声明
