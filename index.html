关于 font.onmicrosoft.cn（8 个拉丁字体的来源）

它是一个 npm 镜像站（和 unpkg 同类），代理 @fontsource/* 系列包。 Fontsource 把 Google Fonts 里的开源字体打包成 npm 包，所以从镜像取到的就是官方字体文件—— 这些字体不是本站自制的，也没有经过二次修改，只是换了一个国内能稳定访问的域名。

  • 按需实时加载：这 8 个拉丁字体不打进项目，页面首次打开时按固定版本去取（例如 @fontsource-variable/inter@5.2.5），之后走浏览器缓存
  • 取的是 latin 子集（每个约 100–300 KB），不含中文字形；中文由本项目 fonts/ 提供，两者不重叠
  • 失效会自动降级：镜像打不开时这 8 个字体回退到系统字体，页面不会报错、也不会卡住
  • 想彻底离线或换源：把 index.html 顶部 <style> 里对应的 @font-face 的 src 改成本地文件或自己的 CDN 地址即可

注意事项

  • 直接双击 index.html 也能打开，页面布局、样张都正常显示；但自定义字体能否加载取决于浏览器——多数浏览器把 file:// 页面视为不透明来源（origin: null），会拦截 @font-face 加载本地字体（含同目录，CVE-2019-11730 之后的 Chrome / Edge / Firefox 都这样）。此时中文字体回退到系统字体，8 个拉丁字体走 CDN 不受影响；想看真实字形，在本目录起个服务用 http(s) 打开
  • 部署时 index.html 与 fonts/ 必须放在同一目录（页面用相对路径 ./fonts/... 加载）
  • 想换字体来源：index.html?alibaba=https%3A%2F%2Fcdn.example.com%2Ffonts%2F（值需 encodeURIComponent）
  • 想减小体积：删掉两个 Noto 字体（合计 42MB），页面会自动回退系统字体，其余不受影响
  • 阿里巴巴普惠体 3.0 起已允许自行托管；公开 CDN 或随产品分发前，请核对官方现行法律声明
